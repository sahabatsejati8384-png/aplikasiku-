Instalasi Mode Aplikasi HP (PWA)

Pengguna Android (Chrome)

Ketuk ikon titik tiga (⋮) di pojok kanan atas browser, lalu pilih "Tambahkan ke Layar Utama" (Add to Home Screen) untuk menjalankan SNBP-Santri Pro layar penuh seperti aplikasi native.

Pengguna iPhone / iPad (Safari)

Ketuk tombol Bagikan (Share ) di bilah bawah Safari, gulir ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).

Kartu Ringkasan Hasil (PNG)

File otomatis terunduh. Pada iOS Safari, Anda juga bisa menekan lama gambar untuk menyimpan ke Foto.
